## What's new

- **Create and delete volumes, reset the Drobo.** In the app (Volumes, Advanced) and as
  `drobo volume create`, `drobo volume delete <unit>` and `drobo reset`. The commands were read
  out of Drobo Dashboard 3.6.1 and checked against the 8D's own firmware. All three are
  verified on a real Drobo 8D: a reset takes about four minutes and the unit comes back empty,
  with default settings and one blank volume.
- **Format a new volume.** A new Drobo volume is a raw, write-protected disk. `Format…` on its
  row (or `drobo volume format <unit> --name <name>`) allows writing to it and puts APFS or Mac
  OS Extended on it. Verified, including a checksum-compared write.
- **Choose the volume size when resetting.** `Reset Drobo…` → Volume size afterwards, or
  `drobo reset --volume-size 16TB`. This is what Drobo's software called resizing; on a Drobo it
  always erases everything. **Not yet verified on hardware.**
- **Speed test.** `Speed Test…` on a mounted volume, or `drobo speedtest <volume>`: write and
  read speed in MB/s with the Mac's file cache bypassed.
- **Volumes are listed by name when they are not mounted**, and a unit whose volume was deleted
  no longer shows.

Delete and reset destroy data for good. Each asks for the Drobo's serial number, refuses while
any Drobo volume is mounted, and the driver checks the request against the Drobo's own volume
list before sending anything. Details: [volume management](https://github.com/JoeMatt/drobo-driverkit/blob/master/docs/05-volume-management.md),
[protocol notes](https://github.com/JoeMatt/drobo-driverkit/blob/master/docs/01-protocol-reverse-engineering.md) sections 11.26 and 11.27.

## Good to know

- After creating or deleting a volume, restart the Drobo: it only changes the disks it
  presents when it starts.
- A reset puts drives the Drobo had marked as failed back into use. It does not repair them.
- Writing through this driver is still experimental. Keep another copy of anything you store.
